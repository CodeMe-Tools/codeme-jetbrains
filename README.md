# Codeme for JetBrains IDEs

IntelliJ Platform plugin for IntelliJ IDEA, PyCharm, CLion, RustRover, WebStorm, GoLand, and Android Studio.

## Features
- `CodemeExternalAnnotator`: maps `codeme syntax check --format sarif` diagnostics directly into editor highlights.
- `Codeme Verification` tool window and project settings (`Settings -> Tools -> Codeme`).

## Build
```bash
./gradlew buildPlugin
```
